# Задание. Загрузка разнородных ресурсов данных

- Разработать целевую схему для данных с предыдущего домашнего задания в выбранном
формате (CSV, JSON, …);
- (если требуется) Написать программу разбора исходных страниц и сохранение их в одном
из форматов (CSV, JSON, …);
- Написать схемы источников в одном из форматов (CSV, JSON, …);
- Написать программу преобразования данных из схем источников в целевую схему;
- В результате должно получиться 2 файла исходных данных в схемах и форматах этих
источников данных (CSV, JSON, …), и 2 файла преобразованных исходных данных в
целевой схеме.

# Результат

Схемы (как исходные, так и целевая) описаны в папке schemas

В output_data лежат уже преобразованные к целевой схеме данные

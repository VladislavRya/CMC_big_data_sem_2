# Задание. Слияние данных

- Написать программу слияния данных, реализующую один из следующих вариантов:
  - Реализовать слияние данных на основе функции Fuse By
  - Реализовать слияние данных на основе одной из трех функций: Minimum Union, Complement Union, Merge и дополнительной постобработки, чтобы объединить одинаковые строки или столбцы в одну строку/столбец (например, с помощью группировки/аггрегации)
- Применить эту функцию к данным, полученным в результате выполнения домашнего задания 2;
- В результате должно получиться множество объектов, включающих данные (атрибуты) из обоих входных файлов;
- Результат представляется в одном из форматов (CSV, JSON, …).

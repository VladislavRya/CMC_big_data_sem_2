# Задание. Поиск дубликатов

- Написать программу поиска дубликатов, реализующую один из следующих алгоритмов:
  - Попарное сравнение (на четверку) для реляционных данных
  - Метод на основе непересекающихся блоков (Disjoint Blocking) для реляционных данных
  - Метод сортированных соседей (Sorted Neighborhood) для реляционных данных
  - Метод поиска дубликатов сверху-вниз для иерархических данных
  - Метод поиска дубликатов снизу-вверх для иерархических данных
- В результате должен получиться файл, содержащих информацию о дубликатах, например, в виде уникального идентификатора для дублированных записей, или в виде объединения дубликатов в одном списке;
- Результат представляется в одном из форматов (CSV, JSON, …).
